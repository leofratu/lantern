Device controls

Device speed and latency

Speed cap

Excess traffic is dropped above each byte budget, with a 16 KiB burst. This is a rate cap rather than smooth queue shaping. Rules clear on gateway reboot. Offloading must be disabled.

Added latency

Delays traffic from the gateway to this device, increasing ping by roughly this amount. Jitter must not exceed delay. Requires disabled offloading and an unused LAN root queue; the policy clears on gateway reboot.
